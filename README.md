# english-conversation

A small collection of visual guides for one-on-one English conversation sessions.

## Structure

- `index.html` — conversation directory
- `conversations/` — one folder per conversation guide

Each guide is a self-contained HTML file with embedded CSS and minimal JavaScript.

## Local preview

Open `index.html` directly in a browser, or run a simple local web server from this directory.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and publish the repository root from the main branch.
